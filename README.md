# Glint

Glint is a light, AI-native web browser for the Mac, built on the system's WebKit.

This repository holds Glint's signed and notarized downloads, and `appcast.xml`, the feed Glint checks once a day for updates. Glint's code lives elsewhere.

**Download:** the latest `.dmg` under [Releases](../../releases/latest). Open it and drag Glint to Applications. From 0.1.9 on, Glint updates itself: when a new version has downloaded, an Update button appears in the toolbar.
